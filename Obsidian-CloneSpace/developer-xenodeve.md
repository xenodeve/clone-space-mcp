- **Expects work carried through.** Not "here is a patch" — issue → PR → review → merge → sync →

- **Requires proof before a claim** ([[evidence-before-claims]]). Corrections are welcome and
  taken plainly; unearned confidence is not.
- **Reads screenshots carefully.** A claim that contradicts something they have shown you is very
  likely the claim that is wrong.
- **Working style:** parallel work on several repos, temporary git worktrees so in-progress
  branches are never disturbed.
